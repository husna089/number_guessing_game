# Number Guessing Game

A Bash game that generates a random secret number between 1 and 1000.

## Requirements
- Bash
- PostgreSQL
- Database named `number_guess`
- PostgreSQL user `freecodecamp`

## How to Run

Make the script executable:

```bash
chmod +x number_guess.sh


./number_guess.sh

```

The game stores usernames and game statistics in PostgreSQL.
